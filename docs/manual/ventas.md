# Las ventas

Acá están todas las ventas del local, con qué se vendió y cómo se pagó.

## Buscar una venta

Se busca de dos formas:

- Por **número**: escribí `#12`.
- Por **lo que dice**: escribí `campera` y aparecen todas las ventas que
  incluyeron una.

La segunda es la que se usa de verdad: en el mostrador uno se acuerda de "la
campera de ayer", no de un número.

## El detalle

Tocando una venta se abre lo que se llevó el cliente, cuánto se descontó,
cuánto se cobró y con qué medios.

## Anular una venta

Si una venta se cargó mal, se anula. Escribí el motivo y tocá **Anular la
venta**.

La venta **no se borra**: queda marcada como anulada, con tu nombre y el
motivo. Si se borrara, la plata que entró a la caja quedaría sin nada que la
explique y el arqueo no cerraría.

El sistema devuelve la plata a la caja automáticamente, con un movimiento por
cada medio con el que se había cobrado. Después cargá la venta de nuevo bien.

### Por qué me pide abrir la caja para anular una venta de ayer

Porque la plata tiene que volver a alguna caja, y la de ayer ya está cerrada
con su arqueo contado y firmado. Meter una devolución ahí cambiaría un número
que alguien ya revisó.

La devolución entra en la caja de hoy, que es como se hace también en papel:
una nota de crédito se emite el día que se emite, no se mete en el mes ya
cerrado.

### Por qué el precio de una venta vieja no cambió cuando actualicé el catálogo

Porque cada venta guarda el precio con el que se vendió. Si cambiara junto con
el catálogo, no habría forma de saber a cuánto vendiste el mes pasado, ni
cuánto ganaste.
