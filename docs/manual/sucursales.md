# Sucursales

Una sucursal es un lugar físico del negocio: un local que vende, o un depósito
que solo guarda mercadería. Esta pantalla la ve solo el administrador.

## Para qué sirve si tengo un solo local

El sistema está preparado desde el principio para más de un local, aunque hoy
haya uno solo.

Cada venta, cada movimiento de mercadería y cada cierre de caja quedan
guardados con el local al que pertenecen. Si el día de mañana abrís otro, o un
depósito, no hay que rehacer nada de lo anterior: la mercadería y las ventas
viejas ya tienen su lugar anotado.

## Local y depósito

Los dos tienen mercadería y reciben envíos. La diferencia:

- El **local** vende y abre caja.
- El **depósito** no vende ni abre caja: solo guarda y manda.

## Dar de alta una sucursal

Hacen falta el nombre, un código corto y el tipo.

El **código** es para reconocerla de un vistazo en los listados, sobre todo en
el celular, donde no entra el nombre completo. Se escribe siempre en
mayúsculas, así no conviven "dep" y "DEP" como si fueran dos lugares
distintos.

El **punto de venta** es un número que da ARCA y sirve para facturar. Se carga
cuando se habilite la facturación electrónica; hasta entonces puede quedar
vacío. Cada sucursal necesita el suyo: dos locales no pueden compartir la
numeración de las facturas.

## Cuando el sistema no te deja

### No me deja cambiar el código de una sucursal

Ese código quedó escrito en los movimientos de mercadería y en las ventas ya
hechas. Si se cambiara, esos movimientos pasarían a nombrar un local que no
existe.

El nombre, la dirección y el teléfono sí se pueden corregir cuando quieras.

### Dice que ya existe una sucursal con ese código

Dos sucursales no pueden tener el mismo código, porque es lo que las
distingue en los listados y en los movimientos. Elegí otro.
